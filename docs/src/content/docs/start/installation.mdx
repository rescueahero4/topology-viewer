## Install

Topology Viewer installs from GitHub, and it builds during the install.

<Tabs syncKey="pm">
  <TabItem label="npm">
    ```sh
    npm install git+https://github.com/rescueahero4/topology-viewer.git
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```sh
    pnpm add github:rescueahero4/topology-viewer
    ```
  </TabItem>
  <TabItem label="yarn">
    ```sh
    yarn add github:rescueahero4/topology-viewer
    ```
  </TabItem>
</Tabs>

React 18 or newer is an optional peer dependency. You only need it for `topology-viewer/react`.

## Update

Run the same command again. A plain `npm install` keeps the commit in your lockfile, so it does not update the package.

To check which commit you have:

```sh
npm ls topology-viewer
```

## Entry points

| Import | Gives you | Size |
|---|---|---|
| `topology-viewer/react` | `TopologyViewer`, `createTopologyViewer`, `defineProfile` | Loads the core, about 180 KB gzipped |
| `topology-viewer` | `mountTopology`, for any framework or none, and `defineProfile` | Loads the core, about 180 KB gzipped |
| `topology-viewer/profiles/qdic` | `qdicProfile`, an optional data catalog vocabulary with icons | 14 KB gzipped |

<Aside type="tip">
The core is large for a component, because it is a whole application. To keep your first page light, load it with `next/dynamic`, `React.lazy` or `client:only`. See [Frameworks](/topology-viewer/start/frameworks/).
</Aside>

## TypeScript

The types come with the package, with a description for every option and command, so your editor shows them on hover. You do not need `@types/*`.

```tsx
import type {
  TopologyOptions,
  TopologyPart,
  TopologyTheme,
  TopologyViewerRef,
} from "topology-viewer/react";
```
