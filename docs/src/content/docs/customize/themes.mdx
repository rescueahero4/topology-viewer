## The `theme` prop

A key names a token: `frameRadius` is `--tv-frame-radius`, and `family0Tint` is `--tv-family-0-tint`.

## From CSS

Tokens are CSS custom properties, so you can set them from your own CSS. They inherit into the viewer through its Shadow DOM.

```css
.my-viewer {
  --tv-frame-radius: 0;
  --tv-accent: #7c3aed;
  --tv-font: "Inter", sans-serif;
}
```

```tsx
<TopologyViewer className="my-viewer" url="/api/graph" />
```

The two are the same tokens. Use whichever fits your project. CSS is handy when your design system already sets custom properties:

```css
.my-viewer {
  --tv-accent: var(--brand-primary);
  --tv-surface: var(--panel-background);
}
```

## The tokens that matter most

| Key | Sets |
|---|---|
| `canvas` | The background of the chart |
| `surface` | The background of cards and menus |
| `text`, `textMuted`, `textStrong` | Text |
| `border` | Lines |
| `accent`, `focus` | Selected things and the focus ring |
| `frameRadius`, `frameBorder` | The outer frame |
| `radius`, `radiusSm`, `radiusPill` | Corners |
| `font`, `fontCanvas` | Fonts |
| `fontSize1` to `fontSize7` | Type sizes, from 8 to 14 px |

There are about 90 in all, including every family colour. See the [full list with defaults](/topology-viewer/reference/tokens/).
