## Everything is included, and everything is yours to change

<CardGrid>
  <Card title="A full explorer" icon="puzzle">
    Five layouts, grouping, focus, hide and restore, search, filters, an inspector and an editable table.
  </Card>
  <Card title="Every element is addressable" icon="pencil">
    Every element has a public name that works in CSS and in props. Use tokens, `::part`, inline styles or Tailwind.
  </Card>
  <Card title="Your components inside" icon="seti:react">
    Replace any part with your own React, including the nodes on the canvas. Your CSS and React context keep working.
  </Card>
  <Card title="Safe to embed" icon="approve-check">
    It runs in its own Shadow DOM, has no runtime dependencies, and needs no `unsafe-eval` or `unsafe-inline`.
  </Card>
</CardGrid>
