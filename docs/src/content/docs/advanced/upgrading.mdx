---

## Breaking changes

### `variant` defaults to `"page"`

The default look has labels on its controls, and square corners. For the old compact look, which also has the rounded frame:

```tsx
<TopologyViewer variant="widget" />
```

### Full screen fills the browser view

It no longer uses the Fullscreen API by default. To keep the old way:

```tsx
<TopologyViewer fullscreen="native" />
```

See [Full screen](/topology-viewer/components/fullscreen/). The button now also shows in the `page` variant.

### `onSave` gets only the new changes

It used to get every change so far on each save, so a second save sent the first one again.

```tsx
// Before: changes held everything so far.
onSave={(changes) => send(changes)}

// Now: changes holds what is new. The full list is here.
onSave={(changes, { all }) => send(all)}
```

It can also return a promise, and the bar waits for it. See [Saving](/topology-viewer/components/saving/).

### The search shortcut ignores Ctrl and Cmd

`/` with Ctrl or Cmd held no longer focuses the search.
