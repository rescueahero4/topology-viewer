A key works only while the pointer or the focus is in the viewer, and typing in a text field stays typing. So the viewer does not take keys from your page.

<Demo name="keyboard" height={520} />

## The keys

| Name | Default | Does |
|---|---|---|
| `search` | `/` | Focuses the search |
| `toggleTable` | `mod+.` | Opens or closes the table |
| `tableSmaller` | `[` | Makes the table smaller |
| `tableLarger` | `]` | Makes the table larger |
| `undo` | `mod+z` | Undoes an edit, in the table |
| `redo` | `mod+shift+z` | Redoes an edit, in the table |
| `escape` | `escape` | Closes a menu or the full view, or clears the selection |

`mod` is Ctrl or Cmd. You can also write `ctrl`, `meta`, `shift` and `alt`.

## Change them

```tsx
<TopologyViewer keyboard={{ search: "mod+k", tableLarger: false }} />
```

`false` switches off one key. To switch off all of them:

```tsx
<TopologyViewer keyboard={false} />
```

<Aside type="note">
These do not change the keys of accessibility: Tab, the arrow keys in menus and in the table, Enter and Space on a node.
</Aside>
